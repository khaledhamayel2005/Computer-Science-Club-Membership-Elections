# CAC Election Desk

نظام داخلي عربي RTL لمنظّمي انتخابات نادي علم الحاسوب في جامعة بيرزيت. يسجل استلام الطالب إذن المشاركة في اقتراع ورقي فقط؛ لا توجد بطاقات أو أصوات إلكترونية.

## التشغيل

1. انسخ `.env.example` إلى `.env.local` وأدخل رابط MongoDB Atlas وسر جلسة عشوائيًا قويًا.
2. عيّن `ADMIN_INITIAL_USERNAME` و`ADMIN_INITIAL_PASSWORD` لأول تشغيل فقط. ينشئ الخادم حساب المدير بكلمة مرور مشفرة عندما تكون مجموعة المديرين فارغة.
3. شغّل `npm install && npm run dev`.

الفهرس الجزئي الفريد `electionId + normalizedStudentId` يمنع التسجيل الفعال المكرر ذريًا، بما في ذلك الطلبات المتزامنة. الإلغاء لا يحذف السجل؛ بل يغير حالته ويحفظ سجل تدقيق.

## النشر على Vercel

أضف متغيرات البيئة المذكورة في `.env.example` في إعدادات المشروع. لا ترفع ملف البيئة إلى Git.
